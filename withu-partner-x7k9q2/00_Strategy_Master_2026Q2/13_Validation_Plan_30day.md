**Output: Which of 4 possible Paths is open:**

```
Path 1: Pure Family-Side Capture
  Email forward + Photo + Voice + Manual portal pull
  → Validate through 3-family experiment
  → Pass: 70%+ data completeness, no burnout

Path 2: Plaid-style Patient Portal Aggregation
  Family creds → WithU auto-pulls from TheraNest etc.
  → Validate through tech advisor + portal docs
  → Pass: feasible API or scrape exists

Path 3: Direct Local Therapy SaaS Partnership
  Phase 2 strategy: integrate with TheraNest / Fusion / WebPT API
  → Validate through partnership exploration
  → Pass: at least one major SaaS shows partnership interest

Path 4: Hybrid / Phased
  Day 1: Path 1 (family capture)
  Phase 2: Path 2 (portal aggregation)
  Phase 3: Path 3 (SaaS partnership)
  → Validation: each phase has clear gating criteria
```

**Decision at Day 30:** Which Path (or combination) is realistic = **threads visualized**

## Loop Mini-Experiment (4-Week Detailed Design)

### Week 1: Recruit + Setup

**Target:** 3 families from Tingさん's 100-family network

**Selection criteria:**
- Diverse stages (preschool, school-age, transition)
- Active in WithU community (high motivation)
- Multiple providers (Local PT/OT/ST + medical specialists, minimum 3)
- Tech-comfortable (email forward / photo capable)

### Week 2: Forward Status Monitoring

- 3-family forward / photo / voice activity confirmation
- Burden self-report collection
- Mid-point Path 1 feasibility initial read

### Week 3: Photo OCR + Voice Memo Test

- Photo OCR trial week
- Voice memo prompt distribution
- 1 family invitation test to Local Therapy share

### Week 4: Final Analysis

- Total data completeness calculation
- Family burnout detection
- Local Therapy reaction analysis (accepted / confused / declined)
- Decision: which Path is most feasible

### Tracking Metrics (4 weeks)

| Metric | How Measured | Pass Threshold |
|---|---|---|
| **Forward rate** | # forwards / # provider emails received | > 70% |
| **Photo capture rate** | # photos / # paper docs received | > 60% |
| **Voice note rate** | # voice memos / # sessions attended | > 40% |
| **Manual entry rate** | # times family typed in directly | < 20% of total |
| **Total data completeness** | (forwards + photos + voice + manual) / expected total | > 70% |
| **Burden self-report** | weekly 1-5 scale | Weekly avg < 2.5 |
| **Continued willingness** | "Would you continue after experiment?" | > 60% YES |

### Local Therapy View Test (Week 3-4)

**Setup:** 1 family invites their own Local Therapist (PT or OT) to view WithU record

**Track:**
- Therapist response time
- Did they actually open / read?
- Useful or overwhelming reaction?
- Would they accept similar requests from other families?
- What blocked them (if any)?

### Decision Tree (End of Week 4)

```
IF Total completeness > 70% AND burden < 2.5 AND continuation > 60%:
  → Path 1 (Pure family capture) VALIDATED
  → Phase 1 strategy proceeds confidently
  → Phase 2 plan: enhance with Path 2 (portal aggregation)

IF completeness 40-70% OR burden > 3:
  → Path 1 partially viable
  → Need Path 2 / Path 3 in MVP
  → Tech advisor consultation for Plaid model feasibility

IF completeness < 40% OR burden > 4:
  → Path 1 fails
  → Need direct Local Therapy integration earlier than planned
  → Phase 1 strategy major revision

IF Local Therapy reaction is "useful":
  → Cross-stakeholder positioning validated
  → Phase 2 partnership pathway open
  
IF Local Therapy reaction is "overwhelming / no thanks":
  → Cross-stakeholder positioning weaker than thought
  → Reconsider value prop framing
```
