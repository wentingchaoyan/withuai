本プライバシーポリシーは日本国内のユーザーを対象としています。 米国のユーザーは英語版プライバシーポリシーをご参照ください。

1. はじめに

当社は、子供の発達支援アプリケーション（以下「本アプリ」）におけるユーザーのプライバシーを尊重し、個人情報の保護に最大限の注意を払っています。本プライバシーポリシーでは、本アプリにおける個人情報の取り扱いについて定めています。

2. 収集する情報

本アプリでは、以下の情報を収集する場合があります：

2.1 ユーザー情報

  • メールアドレス

2.2 お子様の情報

以下の情報は、保護者が任意で入力した場合に収集されます：

基本情報（プロフィール作成時）

  • お名前（ニックネーム可）
  • 生年月日
  • 性別
  • プロフィール写真（任意）
  • 診断名（任意）

医療・健康情報（任意）

  • アレルギー情報
  • 既往歴（病名、診断日、治療状況）
  • 合併症・併存疾患
  • 身体測定データ（身長、体重、測定日）

出生時情報（任意）

  • 出生場所、出産方法
  • 在胎週数
  • 出生時の身体測定（体重、身長、頭囲、胸囲）
  • 入院歴（妊娠中、分娩時、NICU、GCU）
  • 出生時診断、妊娠合併症
  • 入院経過、退院後経過
  • 出生時・退院時の写真（任意）

発達特性情報（任意）

  • 好きなこと、苦手なこと
  • 落ち着く方法
  • コミュニケーションスタイル
  • サポートのヒント
  • 家族からのメッセージ
  • 育児の優先事項

生い立ち・ライフイベント（任意）

  • イベント日付、種類、タイトル
  • イベントの説明
  • 場所情報

2.3 記録情報

以下の情報は、保護者がアプリの機能を利用した場合に収集されます：

  • 発達記録・発達マイルストーンチェックデータ
  • 日常の記録
  • 動画データ（AI分析用にアップロードした場合）
  • AI分析結果（姿勢・動作データを含む）
  • LLM生成の発達提案

2.4 出力・共有データ

以下の機能を利用した場合、上記の情報を含むデータが生成されます：

  • PDFエクスポート機能（プロフィール情報、医療情報等を含む）
  • サポートブック作成機能
  • 共有機能（他の保護者・支援者との情報共有）

2.5 子供の情報取り扱いについて（事前同意）

本アプリをご利用になる保護者は、以下の事項に事前に同意したものとみなします：

  1. 13歳未満の子供の情報を扱う可能性があること
  2. 子供の情報取り扱いに関する親の同意を事前に与えること
  3. 子供の年齢確認時に追加の同意確認を行う場合があること
  4. 子供の正確な位置情報は収集しないこと
  5. 子供の個人識別情報の第三者共有は行わないこと

3. 情報の利用目的

収集した情報は、以下の目的で利用されます：

  1. 本アプリの提供・運営
  2. 発達支援サービスの提供
  3. AI分析機能の提供
  4. LLM生成機能の提供
  5. 動画解析・姿勢分析の実行
  6. 発達マイルストーンの評価
  7. ユーザーサポート
  8. サービスの改善
  9. セキュリティの確保
  10. 分析精度向上のための研究開発（匿名化データ）

4. 情報の管理

1. 当社は、収集した個人情報を適切に管理し、以下の措置を講じます：

  • アクセス制限の設定
  • データの暗号化
  • セキュリティ対策の実施
  • 従業員への教育
  • 動画データの安全な保存
  • AI分析データの暗号化保存
  • LLM生成データの適切な管理

2. 個人情報の取り扱いを委託する場合は、適切な監督を行います。

3. 動画データは一定期間後に自動削除されます。

4. AI分析結果は暗号化して保存し、分析精度向上のため匿名化されたデータを研究開発に利用する場合があります。

5. 情報の共有

当社は、以下の場合を除き、個人情報を第三者に提供することはありません：

  1. ユーザーの同意がある場合
  2. 法令に基づく場合
  3. お子様の福祉のために必要と判断される場合
  4. 本アプリの利用目的の範囲内で、必要な最小限の情報を共有する場合
  5. 専門家や支援施設との情報共有（ユーザーの同意に基づく）
  6. AI分析精度向上のため、匿名化されたデータを研究開発に利用する場合

5.1 子供データの特別保護（COPPA準拠）

13歳未満の子供の情報については、以下の特別な保護措置を講じます：

  1. 子供の個人識別情報の第三者共有は行いません
  2. 子供向けのターゲティング広告は行いません
  3. 子供のデータ販売は行いません
  4. 子供の正確な位置情報は収集しません
  5. 子供のデータは必要最小限のみ収集します
  6. 子供のデータは特別な暗号化で保護します

6. データの保存期間

  1. 個人情報は、利用目的の達成に必要な期間のみ保存します。
  2. 動画データは3年後に自動削除されます。
  3. AI分析結果は5年間保存されます。
  4. LLM生成データは3年間保存されます。
  5. アカウントの削除時には、関連する個人情報も適切に削除します。
  6. 匿名化された研究データは、分析精度向上のため長期保存される場合があります。

7. ユーザーの権利

ユーザーは、以下の権利を有します：

  1. 個人情報の開示請求
  2. 個人情報の訂正・削除請求
  3. 個人情報の利用停止請求
  4. データのエクスポート請求

7.1 データ処理の法的根拠（GDPR対応）

EU域内のユーザーについては、以下の法的根拠に基づいてデータを処理します：

  1. 契約の履行：本アプリのサービス提供
  2. 正当な利益：サービスの改善・分析
  3. 明示的同意：追加的なデータ処理
  4. 法的義務：法令に基づく処理

7.2 国際データ転送について

当社は、以下の場合にデータを国際転送する場合があります：

  • AI分析サービスの提供（米国等）
  • クラウドストレージサービス（米国等）
  • 適切な保護措置を講じた上で転送を行います

7.3 カリフォルニア州居住者の権利（CCPA対応）

カリフォルニア州居住者は、以下の追加権利を有します：

  1. 個人情報の開示請求権
  2. 個人情報の削除請求権
  3. 個人情報の販売拒否権
  4. 差別待遇を受けない権利

請求方法：admin@withuai.com までご連絡ください

8. セキュリティ対策

当社は、以下のセキュリティ対策を実施しています：

  1. SSL/TLSによる通信の暗号化
  2. アクセス制御の実施
  3. 定期的なセキュリティ監査
  4. インシデント対応計画の策定

9. クッキー（Cookie）の使用

本アプリでは、以下の目的でクッキーを使用する場合があります：

  1. ユーザー認証
  2. 利用状況の分析
  3. サービスの改善
  4. AI分析機能の最適化
  5. LLM生成機能の精度向上

10. プライバシーポリシーの変更

  1. 当社は、必要に応じて本プライバシーポリシーを変更することができます。
  2. 変更後のプライバシーポリシーは、本アプリ上での告知をもって効力を生じるものとします。

12. 第三者サービスの利用

本アプリでは、以下の第三者サービスを利用しています。これらのサービスは、それぞれのプライバシーポリシーに従ってデータを処理します。

12.1 Firebase（Google LLC）

  • 利用機能：Crashlytics（クラッシュレポート）、Analytics（利用状況分析）
  • 収集データ：クラッシュログ、デバイス情報、アプリ使用状況、セッション情報
  • 目的：アプリの安定性向上、サービス改善
  • プライバシーポリシー：https://firebase.google.com/support/privacy

12.2 Supabase

  • 利用機能：ユーザー認証、データベース、ファイルストレージ
  • 収集データ：アカウント情報（メールアドレス）、発達記録、動画・画像ファイル
  • 目的：アプリの基本機能提供
  • データ保存場所：米国
  • プライバシーポリシー：https://supabase.com/privacy

12.3 Expo

  • 利用機能：アプリケーション基盤、アップデート配信
  • 収集データ：デバイス情報、アプリバージョン情報
  • 目的：アプリの動作基盤提供
  • プライバシーポリシー：https://expo.dev/privacy

12.4 MediaPipe（Google）

  • 利用機能：動画解析、姿勢分析
  • 処理方法：デバイス上でのローカル処理（動画データはサーバーに送信されません）
  • 目的：発達評価のためのAI分析
  • プライバシーポリシー：https://policies.google.com/privacy

13. 準拠法

本プライバシーポリシーは、日本法に準拠して解釈されるものとします。
